01 / THE APPROACH

From loan records
to risk signals.

Two complementary objectives: predict default and understand the borrower characteristics associated with risk.

01

Prepare the data

Remove features with ≥65% missing values; impute remaining missing values with medians. Address extreme income values and redundant predictors.

02

Protect the prediction

Exclude post-origination information. Encode default as the positive class, split training and test data, and standardize features.

03

Model & compare

Evaluate regularized logistic regression and weighted Gradient Boosting. Optimize recall through cross-validation to prioritize missed defaults.

04

Explore the structure

Use scaled features, PCA and K-Means to investigate borrower segments. Compare patterns in income, housing, loan size and term.

Methodology summarized from the supplied report. Notebook implementation and preprocessing order remain to be verified when the code is provided.

02 / MODEL PERFORMANCE

High recall.
A visible trade-off.

Defaults are the minority class. Recall measures how many actual defaulters are detected; precision reflects how many flagged borrowers actually default.

Why Elastic Net?

The report favors its combination of interpretability, strong discrimination and regularization, which shrinks uninformative feature coefficients.

What does high recall cost?

Reported Elastic Net precision is approximately 54%. Many borrowers flagged as risky did not default, making the decision threshold a consequential business choice.

A central finding: simplicity held up

More elaborate approaches did not deliver a clear advantage over Elastic Net. Weighted Gradient Boosting achieved comparable recall, while several extensions added computation without improving default detection.

BEYOND THE BEST MODEL

More complexity.
No clear advantage.

A major result of this project is that additional modeling complexity did not consistently improve the business-critical outcome: identifying defaulters. Some approaches performed worse; others produced similar results at a greater computational cost.

The modeling exploration included Ordinary Least Squares, K-Nearest Neighbors, support vector machines and Random Forest, alongside Lasso, Ridge and Elastic Net logistic regression and Gradient Boosting. The report identifies Elastic Net and weighted Gradient Boosting as the strongest performers; it does not provide individual test metrics for every exploratory model.

What the additional experiments revealed
ExperimentReported resultWhat it means
Polynomial & interaction features91.2% recall; 0.964 ROC-AUCAdding squared interest rate and a loan-amount × income interaction slightly reduced recall from 91.5%, with no gain in ROC-AUC.
Forward feature selection65 selected features; similar performanceRepeated five-fold cross-validation was computationally expensive and added no predictive benefit over Elastic Net’s existing regularization.
PCA + logistic regression~63% default recall; ~94% accuracyRetaining 99 components explaining 95% of variance still sharply reduced default detection. High overall accuracy concealed weaker minority-class performance.
Gradient Boosting without balancing~70% default recallIntroducing balanced sample weights raised recall to ~92%. Handling class imbalance proved essential to making the more complex model competitive.

Accuracy can hide missed defaults

PCA plus logistic regression reached approximately 94% accuracy but missed about 37% of actual defaulters. Elastic Net missed about 8.5%, illustrating why recall guided model selection.

Regularization already did useful work

Elastic Net shrank uninformative coefficients while retaining predictive performance. More feature transformations and a separate selection procedure offered little additional value in the reported experiments.

A practical case for interpretability

With weighted Gradient Boosting delivering comparable recall, the author favored Elastic Net for its transparency and practical implementation. Complexity alone was not a reason to prefer a model.

These are report-supplied results, not independently reproduced measurements. The numerical table gives Elastic Net the higher ROC-AUC; a contradictory sentence in the report is not used here.

03 / BORROWER SEGMENTATION

Risk has a context.

K-Means revealed four segments differentiated by housing status, income, loan size and term. Associations help frame further research.

CLUSTERS 0 & 3

Mortgage-heavy profiles

The report describes higher incomes, larger loans and lower default rates in these segments.

CLUSTERS 1 & 2

Rent-heavy profiles

Lower incomes and smaller loans generally coincide with higher default rates, particularly in cluster 1.

Correlation needs care.

Housing status does not establish a cause of default. Financial variables can reflect historical socioeconomic disparities. The report proposes propensity score matching and verified rent-payment history as future work.

04 / BUSINESS INTERPRETATION

Balance missed defaults
against rejected good loans.

High recall can reduce exposure to defaults while increasing false positives and foregone interest. A practical decision requires validated costs, calibrated probabilities and an explicit lending threshold.

Explore the corrected economic scenario

Using a $15,000 average loan principal, a 13% interest rate and a three-year term, the corrected report estimates baseline net profit of approximately $1.313 billion and model net profit of $1.668 billion: an uplift of approximately $355 million (+27%). Estimated default losses fall from $1.028 billion to $87 million, while foregone interest from rejected good borrowers is approximately $293 million.

These illustrative estimates retain the report’s simplified assumptions and existing treatment of opportunity costs. They are not independently validated financial outcomes.
